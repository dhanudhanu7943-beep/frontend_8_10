What is React?

React is an open-source JavaScript library developed by Meta for building dynamic, high-performance user interfaces (UI), especially single-page web applications.

React = Component-Based Declarative UI Library
2

Is React a Library or Framework?

React is a library, not a framework. It focuses solely on the view layer (UI). Developers are free to choose routing (React Router), state management (Redux, Zustand), and styling tools as needed.

3

What is a Component?

A component is an independent, self-contained, and reusable piece of UI. Components accept arbitrary inputs called props and return React elements describing what should appear on screen.

Navbar Button LoginForm ProductCard
4

Why are Components Important?

  • Reusability: Write once and use across multiple views.
  • Maintainability: Update logic in one component without breaking others.
  • Modularity: Divide complex layouts into small, manageable pieces.
5

What is JSX?

JSX stands for JavaScript XML. It provides an expressive HTML-like syntax inside JavaScript files, compiled by Babel into React.createElement() calls.

Virtual DOM & Reconciliation

The Virtual DOM is a lightweight in-memory representation of the browser's Real DOM. When state changes occur:

  1. React re-renders the Virtual DOM tree.
  2. Diffing algorithm compares previous vs new tree.
  3. Batch updates only the exact changed nodes in Real DOM.

⚡ Quick Comparison: Real DOM vs Virtual DOM

Feature Real DOM Virtual DOM
Update Speed Slow (causes browser reflow & repaint) Fast (in-memory diffing)
DOM Manipulation Expensive computation Minimal updates via batch patching
Memory Usage Higher memory footprint Lightweight JavaScript objects
